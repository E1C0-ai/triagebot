TriageBot — Privacy Policy

Last updated: 2026-11-26. Developer: E1C0 (individual developer). Contact: arsdgjin@gmail.com.

What TriageBot does

TriageBot is a Forge + Rovo agent for Jira. It reads Jira issues in the site where it is installed, ranks and groups them, and drafts first replies. A human approves every action; TriageBot never closes, reassigns, or comments on issues by itself.

Data collection

TriageBot does not collect, copy, or store personal data in its own systems. It holds only the read:jira-work scope and reads issue data at request time through the Atlassian APIs. Issue titles, summaries, and scores are processed in memory for the single request and are not retained, sold, or shared with third parties.

Optional LLM wording polish

By default TriageBot makes no model calls and no network requests outside Atlassian. If a user opts in and supplies their own OpenAI-compatible API key for one call, a single issue's title, summary, band, and score are sent to that provider to polish the wording of a draft reply. The key is held in memory only, never stored, and any failure falls back to the local draft. Decisions (priority band, score, team, response time) are never delegated to the model.

Data retention

No personal data is retained. No data is cached for longer than the single request.
