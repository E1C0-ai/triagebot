TriageBot — live demo

The same engine the Forge + Rovo agent calls (src/triage.js), running in your browser. No server, no key, no data leaves this page. Paste your own Jira issues as JSON, or try a sample.

All computation happens locally in your browser — nothing is uploaded. TriageBot only assists analysis: it never modifies a Jira issue. Every action needs a human to confirm. Privacy by default: with LLM polish off (the default), this page makes zero network requests. The optional LLM only ever receives one issue at a time, and only when you turn it on.

Each issue: key, title, summary, type (Bug / Incident / Story / Task), created (ISO date). Missing fields are tolerated — see warnings below.

✨ Optional: LLM-polished draft replies

Priority, duplicates and team are always decided locally — the LLM only rewrites the wording of one draft reply at a time. It never changes the band, score, team or response time.

Your key is read when you click “Polish” and held only in memory: it is never written to a file, localStorage, or a cookie, and it is only sent as an Authorization header to the endpoint above. Each polish sends a single issue's title, summary, band, score and team — never the whole backlog. If the LLM fails or you leave the key empty, the local draft stays and you are told why.
